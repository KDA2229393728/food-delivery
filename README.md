# Демо-сайт доставки еды

Готовый пример: меню → корзина → оформление заказа → уведомление в Telegram.

## 1. Создайте Telegram-бота
1. В Telegram откройте **@BotFather**.
2. Отправьте `/newbot`.
3. Задайте имя и username бота.
4. BotFather выдаст токен — сохраните его.

## 2. Узнайте свой Telegram Chat ID
1. Напишите созданному боту любое сообщение.
2. В браузере откройте:
   `https://api.telegram.org/botВАШ_ТОКЕН/getUpdates`
3. Найдите `"chat":{"id":123456789}` — число и есть ваш Chat ID.

## 3. Настройте проект
Скопируйте `.env.example` в `.env` и заполните:

TELEGRAM_BOT_TOKEN=...
TELEGRAM_CHAT_ID=...

## 4. Запуск
Установите Node.js 18+.

В папке проекта:
```bash
npm install
npm start
```

Откройте:
http://localhost:3000

## 5. Как сделать QR-код
После публикации сайта у вас будет адрес вроде:
`https://my-food.ru`

Именно этот адрес нужно зашить в QR-код. QR можно напечатать на столах, визитках, листовках и упаковке.

## Важно
Токен Telegram-бота хранится только на сервере в `.env`. Не вставляйте его в `app.js` или HTML — иначе его сможет увидеть любой посетитель сайта.
